# CodeMotive brand asset kit

Every file is named `what-it-is-size-variant`. SVG and PDF are vector (scale to any size, use for print and web).
PNG is for places that need an image upload. "color" = for light backgrounds, "reversed" = for dark backgrounds.

| Folder | What's inside | Use it for |
|---|---|---|
| 01-master-logos | Primary stacked, horizontal, icon mark and wordmark in color and reversed. SVG + PDF + 3000px transparent PNG | Source files for everything. Send these to printers, designers, developers |
| 02-mono-and-reversed | Same four lockups in single colour: black, white, forest, charcoal. Plus ready-made white-on-forest and reversed-on-charcoal PNGs | Stamps, engraving, embroidery, one-colour print, photos, watermarks |
| 03-social-profile-pictures | Instagram 1080, Facebook 720, LinkedIn company 400 and personal 800, WhatsApp Business 640, X 400, YouTube 800, TikTok 720, Google Business 720, GitHub 500. `light-alternative/` has the warm-neutral versions | Profile pictures. Circle-crop safe |
| 04-social-cover-banners | Facebook 1640x624, LinkedIn company 1128x191, LinkedIn personal 1584x396, X header 1500x500, YouTube 2560x1440, WhatsApp/catalog 1200x630, Zoom/Teams background 1920x1080 | Cover images. Logo sits inside each platform's safe area so profile pictures and mobile crops don't cover it |
| 05-website | Header logo for light mode and dark mode (SVG + PNG at 48/64/96/128px high), header icon, stacked footer logo, Open Graph share image 1200x630 | Website navbar, footer, link previews on WhatsApp/LinkedIn/Facebook |
| 06-favicons | favicon.ico (16-256), favicon.svg, PNG 16-256, apple-touch-icon 180, android-chrome 192/512, maskable 512, mstile 150, safari-pinned-tab.svg, site.webmanifest, browserconfig.xml, html-head-snippet.html | Browser tab icon and "add to home screen". Copy all files to the site root and paste the snippet into `<head>` |
| 07-app-icons | iOS 1024 App Store icon plus all iOS sizes, Android Play Store 512, launcher mipmaps (mdpi-xxxhdpi), adaptive icon foreground/background/monochrome layers, rounded preview | Mobile apps and app stores |
| 08-email-signature | Horizontal logo 600x150 (white bg, transparent, dark bg), 200px icon, HTML signature template | Gmail / Outlook signatures. Displays at 200-300px wide, 2x for sharp screens |
| 09-print-letterhead-invoice | A4 letterhead header, A4 invoice header, full A4 letterhead page. SVG + vector PDF + 300dpi PNG | Word/Google Docs headers, invoices, quotations, printed stationery |
| 10-brand-guide | Colour codes (HEX, RGB, CMYK), font, contact sheet preview | Keeping everything consistent |

Rules of thumb: keep clear space around the logo equal to the height of the "C" counter; don't recolour, stretch or add effects; below 24px use the icon mark only.
